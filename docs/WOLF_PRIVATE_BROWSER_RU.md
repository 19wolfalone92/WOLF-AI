# 🐺 WOLF Private Browser — безопасный режим с авторизацией (14.0)

Это **не GitHub Actions**: настоящий браузер с твоими аккаунтами запускается
на **твоём собственном компьютере** (Windows/macOS/Linux). Мощная видеокарта не нужна.
Профиль Chrome/Chromium хранится в `~/.wolf-ai/private-browser/<profile>` и
не отправляется в GitHub, ChatGPT, Hugging Face или на чужой сервер.

## Установка
Нужны Python 3.11+, Git и доступ к компьютеру.

1. Скачай/клонируй репозиторий `19wolfalone92/WOLF-AI`.
2. В папке репозитория выполни:
   ```bash
   python -m pip install "playwright==1.64.1"
   python -m playwright install chromium
   ```
   На Linux может понадобиться `python -m playwright install --with-deps chromium`.
3. Первичная ручная авторизация, например в собственной тестовой учётной записи:
   ```bash
   python -m wolf_ai.private_browser login --profile my-site --url https://example.com
   ```
   Программа откроет видимый Chromium. Войди **сам**, включая двухфакторную проверку,
   затем вернись в терминал и нажми Enter. WOLF не принимает и не сохраняет пароль
   отдельно — состояние браузера остаётся в локальном профиле.
4. Прочитать открытие уже авторизованного сайта без действий:
   ```bash
   python -m wolf_ai.private_browser inspect --profile my-site --url https://example.com
   ```
5. Выполнить последовательность безопасных навигационных действий (без форм и отправок):
   ```bash
   python -m wolf_ai.private_browser navigate --profile my-site --url https://example.com --steps "Профиль > Настройки"
   ```
   Перед кликами WOLF покажет маршрут и потребует в терминале **YES**.

## Безопасность и ограничения
- Не запускай такой профиль на чужой машине, публичных GitHub Actions или
  незащищённых облачных хостах. Скрипт специально отказывает в CI/GITHUB_ACTIONS.
- Никогда не коммить папку профиля или сохранённые cookies, не загружай их в ZIP.
- Chrome-данные могут позволить войти в аккаунт без пароля. Папка имеет
  приватные разрешения на POSIX, но не заменяет шифрование диска.
- Все маршруты ограничены одним HTTPS-доменом и максимум четырьмя точными
  безопасными пунктами; встроенная проверка прекращает переход на другой домен.
- Сайт может перестроить интерфейс, начать неожиданный процесс или
  запретить автоматизацию. Сверяй результат вручную.
- Программа открывает **видимый** браузер и не загружает скриншоты,
  содержимое личных страниц или cookies куда-либо.
- Этот приватный компонент **пока не связан с мобильным приложением по сети**:
  команды запускаются на компьютере. Для безопасной связки понадобится
  сопряжение устройств, локальная проверка ключей и раздельные разрешения.
- Для внешних публикаций предпочитай официальный OAuth/API Metricool, а не
  имитацию нажатий на публикацию в чужом веб-интерфейсе.

## Почему нельзя просто копировать браузерную сессию в GitHub Actions?
Playwright предупреждает: файл `storageState` содержит чувствительные cookies
и может позволить выдать себя за владельца аккаунта. Публичный репозиторий и
обычные CI artifacts — неподходящее место для такого файла.
Сессионный профиль должен оставаться на устройстве, которому ты доверяешь.

Документация Playwright: https://playwright.dev/docs/auth

## На Android
Во встроенном браузере WOLF можно войти на сайт вручную, подтвердить
навигационный маршрут, заполнить одно текстовое поле **без отправки**
и попросить локальную Qwen объяснить видимый текст страницы. Android WebView
сохраняет собственную сессию в защищённой папке приложения. Не используйте
финансовые, банковские, парольные, платёжные и другие чувствительные операции.
