# WOLF AI 2.1 — автономная разработка с проверяемыми изменениями

WOLF AI — бесплатный Android-контроллер GitHub и локальный ИИ. Новая версия
добавляет ограниченный механизм реального **самоисправления Python-кода**
с тестами и возможностью создания Pull Request.

## 1. Безопасное самоисправление WOLF AI

Кнопка «Самоисправление WOLF AI → Pull Request» вызывает
`.github/workflows/wolf-ai-repair.yml` на основной ветке:

1. В изолированной среде GitHub выполняются тесты WOLF AI.
2. Код проверяется закреплённой версией Ruff 0.14.3.
3. Применяются только безопасные auto-fix правила `F401,F841,I`.
4. Движок ограничивает правки путями `wolf_ai/` и `tests/`;
   запрещает изменения Android, других репозиториев, GitHub Actions,
   более 30 файлов или diff более 120 КБ.
5. Повторно запускаются анализ и тесты.
6. При успешной проверке GitHub **пытается открыть Pull Request**.
7. Отчёт и patch сохраняются в Artifacts до 14 дней, даже при блокировке PR.

Изменения не объединяются в `main` автоматически. Автоматическая
генеративная правка любого кода пока не реализована: данный механизм исправляет
только ограниченную категорию безопасных Python-предупреждений.

GitHub может запрещать Actions создавать PR настройкой
«Allow GitHub Actions to create and approve pull requests». В этом случае
проверенный patch останется в артефакте, но PR не будет открыт.

## 2. Очередь задач GitHub Issues

Кнопка «Отправить задачу в GitHub Issues» публикует текст **только после
явного подтверждения**. Репозиторий WOLF-AI публичный: не добавляй
пароли, токены, личные или коммерческие данные.

Требуется отдельное разрешение **Issues: Read and write**
на `19wolfalone92/WOLF-AI`. Приложение пытается обнаруживать
распространённые секреты, сохраняет номер опубликованной задачи и показывает
список Issues/PR. Создание Issue **не означает, что задача выполняется**.

## 3. GitHub, встроенный ИИ и ограничения

Для запуска Actions требуется fine-grained PAT с **Actions: Read and write**
на WOLF-AI и Two-Worlds-Studio. Публикация Issues использует дополнительное
Issues-разрешение только на WOLF-AI. Токен хранится через Android Keystore.

Qwen2.5-Coder-0.5B и llama.cpp в APK: Termux, платный ИИ API и Work
для локального чата не нужны. Возможности небольшой модели ограничены;
ни её ответы, ни названия задач не исполняются как команды.

Публикация в TikTok, реальные торги, переписывание Williams и
самостоятельное объединение PR запрещены. Work не обходится.
GitHub Actions имеет лимиты.

## 4. Сборка и проверка

GitHub WOLF-AI → Actions → WOLF AI Android — Build APK → Artifacts.
Автоматический CI проверяет исходники и APK, однако работа на конкретном
Android-смартфоне ещё требует проверки. Debug-сборки могут использовать
разные ключи подписи, что может препятствовать обновлению поверх старой
установки с сохранением SQLite-данных.
