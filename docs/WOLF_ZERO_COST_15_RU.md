# 🐺 WOLF AI 15.0 — развитие без обязательных платежей

## Что теперь реально работает бесплатно

**Встроенная Qwen2.5-Coder 0.5B Q4_0** остаётся внутри APK.
Локальная генерация не обращается к API и не требует интернет-соединения.

**Официальные локальные Qwen3 1.7B / 4B Q4_K_M** скачиваются через
Android DownloadManager по Wi-Fi после подтверждения владельцем.
Они бесплатны для локального использования по лицензии Apache 2.0
(проверяй условия модели перед коммерческим распространением).
Скачанная модель хранится на устройстве, SHA-256 сверяется с
предварительно зафиксированным эталоном, затем её можно активировать.
На смартфонах с недостатком оперативной памяти большие модели
не запустятся или будут медленными; это не обещание производительности.

| Модель | Ориентировочный размер GGUF | SHA-256 |
| --- | --- | --- |
| Qwen3 1.7B Q4_K_M, ggml-org | 1.28 ГБ | `d2387ca2dbfee2ffabce7120d3770dadca0b293052bc2f0e138fdc940d9bc7b5` |
| Qwen3 4B Q4_K_M, Qwen | 2.50 ГБ | `7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5` |

Источники для проверки контрольных сумм и лицензии:
- https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF/blob/main/Qwen3-1.7B-Q4_K_M.gguf
- https://huggingface.co/Qwen/Qwen3-4B-GGUF/blob/main/Qwen3-4B-Q4_K_M.gguf
- https://huggingface.co/Qwen/Qwen3-1.7B

Сеть Wi-Fi может иметь собственную тарификацию за трафик.
Для скачивания и установки временно требуется больше места, чем размер
файла, поскольку WOLF проверяет копию до переключения.
При неудаче текущая модель должна остаться неизменной.
Скачанные по DownloadManager модели устанавливаются **только после**
проверки SHA-256 и отдельного подтверждения.

## Нулевой бюджет

По умолчанию `CostGuard.freeOnly() == true`.
Пока включён этот режим, WOLF **не выполняет**
запросы к Hugging Face Inference Providers, даже если токен сохранён.
Перейти к облаку можно только вручную в `☰ → Облачный ИИ`,
с предупреждением о потенциальных тарифах.

**Важно:** это ограничитель облачных LLM-вызовов внутри WOLF,
а не способ запретить платежи в сторонних аккаунтах. GitHub Actions,
Metricool, HF, мобильный интернет и другие услуги имеют свои тарифы,
квоты и условия. Утверждение «весь мир бесплатно и безлимитно»
невозможно.

Актуальные условия Hugging Face Inference Providers:
https://huggingface.co/docs/inference-providers/pricing
Бесплатные пользователи могут иметь малые пробные ежемесячные кредиты;
их размер, срок действия и доступность моделей меняются.

## Как пользоваться

Введи в основном чате:

- `Включи бесплатный режим` — включает блокировку платных облачных LLM API.
- `Статус бюджета` — показывает, включена ли блокировка.
- `Бесплатные модели` или `Улучши локальную модель` — открывает
  каталог 1.7B и 4B, загрузка только по Wi-Fi.
- `Подумай глубже: ...` — локальное трёхэтапное решение
  (план → ответ с локальными данными → самостоятельная проверка).
- `Проведи автономное исследование: ...` — отдельный
  режим реального чтения публичных веб-сайтов и источников,
  не облачный LLM и не скрытая отправка личных документов.

## Почему это ещё не полная замена Work

Генерация ответа одной маленькой моделью и даже два/три локальных
прохода не дают автоматически интеллект облачной GPT.
Работа с интерфейсами Android ограничена Accessibility/разрешениями ОС.
Автоматический вход в облачный браузер и передача cookies через
GitHub Actions намеренно не реализованы по причинам безопасности.
Сильные локальные модели тоже ограничены RAM и вычислениями телефона.

Тесты CI подтверждают сборку исходного кода и правила безопасности.
Производительность конкретной модели проверяется только на реальном
Android-устройстве после её установки.
