# 🐺 WOLF AI 10.0 — понятный русский интерфейс, интернет и Android

## Главное изменение: теперь приложение открывается в ЧАТЕ

Раньше WOLF AI открывал длинный технический экран со множеством
кнопок. Теперь стартовый экран — нормальный диалог:

- сверху логотип WOLF AI, кнопка браузера 🌐 и одно меню ☰;
- в центре история сообщений в «пузырьках», как у современных мессенджеров;
- снизу одна строка «Напиши WOLF любую команду…», кнопка отправки,
  микрофон и переключатель голосового ответа;
- технические панели прошлых версий не удалены, но спрятаны в
  **☰ → Дополнительные инструменты**;
- руководство и список возможностей есть внутри приложения на русском:
  **☰ → Как работает WOLF и его возможности**.

Создан собственный Android-векторный значок с геометрическим волком.
Все команды, описания разрешений и основные сообщения нового интерфейса
на русском языке.

## Примеры — пиши прямо в чат

| Ты пишешь | Что действительно происходит |
| --- | --- |
| «Привет» | Ответ локальной Qwen, если она успешно загрузилась |
| «Объясни закон Ома» | Локальный ответ без платного облачного API |
| «Найди в интернете электронику» | Открывает поисковик DuckDuckGo в браузере WOLF |
| «Открой https://github.com» | Открывает страницу внутри WOLF |
| «Прочитай сайт https://example.com» | После разрешения читает доступный публичный HTML/текст и просит Qwen объяснить |
| «Проверь код WOLF AI» | После разрешения создаёт задачу и вызывает разрешённые тесты GitHub Agent |
| «Покажи батарею» | Читает сведения об устройстве через стандартный Android API |
| «Открой Wi-Fi» | После разрешения открывает экран настроек Wi-Fi |
| «Открой камеру» | Открывает стандартную камеру, не собирая фото без выбора |
| «Открой файлы» | Android даёт выбрать ОДИН файл; индексирование — отдельное разрешение |
| «Позвони +375...» | Только откроет системную звонилку с указанным номером |
| «Выложи видео в TikTok» | Честно предложит технический раздел Metricool: НЕ будет утверждать, что опубликовал видео |
| «Что ты умеешь?» | Откроет подробное руководство на русском |

**Речевой ввод** через системный RecognizerIntent. Распознанная речь
поступает в ту же безопасную систему маршрутизации, что и обычный
текст. По желанию WOLF озвучивает ответы Android Text-to-Speech; первая
озвучка ждёт готовности TTS без повторного нажатия. Некоторые
установленные речевые движки могут передавать звук на их серверы.

## Какой интернет появился

Внутренний браузер действительно открывает веб-сайты и выполняет поиск
через DuckDuckGo HTML. Это **пользовательский браузер WebView**:
- только HTTPS;
- Google Safe Browsing включён;
- чтение file:// и content://, смешанный HTTP-контент запрещены;
- JavaScript отключён по умолчанию; для текущей вкладки можно
  включить его отдельно после предупреждения;
- без JavaScript-bridge, без фонового чтения cookies;
- можно открыть страницу во внешнем браузере;
- сайты с динамическим содержимым/авторизацией могут работать
  ограниченно, особенно когда JavaScript отключён.

Для AI-анализа публичной страницы используется **отдельное**
пользовательское согласие. WOLF не делает вход в аккаунт,
не копирует браузерные куки и не выполняет команды из HTML страницы.
Чтение имеет лимит 140 KB исходного текста; Qwen получает сокращённый
фрагмент с явной ссылкой на URL. Это **не** универсальная замена
Cloud Browser / ChatGPT Work.

## Какой доступ к телефону появился

Через Android Intent / системные приложения — настройки, Wi-Fi,
Bluetooth, камера, файлы, галерея, будильники, карта, календарь,
передача набранного номера в звонилку, SMS-редактор. Для отдельных
действий WOLF запрашивает подтверждение.

WOLF **не имеет** доступа к чужим чатам, скрытым экранным действиям,
рутинному просмотру уведомлений, контактов или микрофону в фоне.
Приложение **не является второй операционной системой** и не имеет
root/AccessibilityService. Такие возможности нельзя честно
обещать без отдельной архитектуры и явных разрешений владельца.

## Память, GitHub и старые проекты

Сохранились функции версий 1–9.1:
- импорт текстовых документов, PDF/DOCX с текстовым слоем;
- локальная база поиска (RAG);
- импорт Qwen GGUF;
- задачи GitHub с отдельным подтверждением;
- связь с видеостудией и Metricool;
- зашифрованный экспорт/восстановление рабочей среды.

Токены остаются в Android Keystore. Веб-страницы и документы
не дают модели полномочий менять чужие приложения или GitHub
без подтверждения.

## Что ещё не реализовано

- Голосовой разговор со стримингом и перебиванием как в ChatGPT Voice.
- Универсальное управление телефоном/экраном других приложений.
- Фоновое наблюдение за экраном, системные права, root.
- Полноценный автономный браузер с кликами, логинами и загрузкой видео.
- Облачная нейросеть уровня GPT-6 без вычислительного сервера.
- Полностью автономная публикация видео без подтверждённого API и OAuth.

## Установка и проверка

Главная Activity: HomeActivity.
Дополнительные инструменты и Metricool OAuth: MainActivity.
Браузер: BrowserActivity. Руководство: GuideActivity.

GitHub CI проверяет Python-контракты, **запускает реальные Java-тесты
маршрутизации**, компилирует Android APK и проверяет артефакт.

CI не заменяет тесты на реальном телефоне: WebView на некоторых
сайтах, системное распознавание речи, Android intents и импорт
GGUF необходимо проверить на устройстве.
