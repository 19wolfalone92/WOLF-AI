# WOLF AI 3.1 — Metricool MCP OAuth (Free compatible)

## Что реально добавлено

WOLF AI 3.1 содержит встроенный **клиент Metricool MCP**. В отличие
от платного REST API Metricool, MCP документирован Metricool как доступный
**включая Free**. Это не даёт бесконечных публикаций: Free — до 20
запланированных постов в месяц, возможны ограничения подключённых сетей.

**Имеется отдельный OAuth 2.1 вход в Metricool, не зависящий от ChatGPT.**
Клиент пытается зарегистрировать себя по DCR, использует PKCE S256,
browser authorization, OAuth code exchange, refresh tokens.
OAuth access+refresh хранятся зашифрованно Android Keystore.
Никаких API ключей или платных сервисов. ChatGPT OAuth в приложение
не переносится.

### ВАЖНО: статус совместимости

**Это интеграция, реализованная и проверяемая при сборке APK, а не
подтверждённое успешное подключение к Metricool аккаунту.**
На момент выпуска нет возможности завершить браузерный OAuth внутри
чата или испытать серверную регистрацию DCR от имени Android-приложения.
Если Metricool отклоняет нестандартный custom-scheme redirect URI,
клиент честно показывает ошибку; не обходит OAuth и не заявляет успех.

## Подтверждаемое пользователем размещение видео

После OAuth и реального ответа MCP getBrandSettings:

1. Ввести числовой brand ID своего Metricool аккаунта.
2. Указать **публично доступный HTTPS URL файла MP4**, с постоянной
   ссылкой. Локальный content:// файл из Android не доступен
   облачным серверам Metricool и не может подставляться вместо URL.
3. Ввести подпись и дату с часовым смещением (например, дата будущего
   дня 19:00 по Минску, ISO-8601 с +03:00).
4. Выбрать TikTok, Instagram, YouTube или Facebook.
5. По умолчанию создаётся черновик. Для попытки автопубликации
   пользователь **сам** включает соответствующую галочку.
6. Перед единственной отправкой MCP инструменту createScheduledPost
   появляется ещё одно окно, где точно перечислены сеть, дата,
   URL, подпись и автопубликация/черновик.

Запрос выполняется только после подтверждения. Никаких фоновых
повторных отправок. При неизвестном результате сверяй Metricool Planner,
чтобы не создать дубликат. Клиент проверяет инструмент и его схему
через настоящий MCP tools/list; при несовместимости не отправляет данные.

Для синтетического видео проставляются признаки AI-generated для
TikTok/Instagram/YouTube. По YouTube по умолчанию madeForKids=false,
а пользователь должен проверить правильность такой настройки
для конкретного видео перед публикацией.

### Безопасность

- OAuth-права mcp:read и mcp:write дают широкий доступ к аккаунту;
  авторизуй только свой аккаунт и отзывай доступ в Metricool.
- Локальное удаление OAuth token также доступно в Android-приложении.
- Клиент жёстко ограничен URL https://ai.metricool.com/mcp и OAuth
  серверам https://app.metricool.com/oauth/*.
- Только инструменты получения брендов и создания поста.
  Доступ к рекламе, сообщениям, изменениям уже запланированных
  публикаций и другим мощным MCP-инструментам **не используется**.
- Никогда не отправляет GitHub PAT, локальные заметки или переписку
  в Metricool.
- Без законной OAuth авторизации, video URL и подтверждения
  пользователя никакая публикация не выполняется.
- В случае отказа подключения продолжает работать старый бесплатный
  интерфейс Android Sharesheet и официальные веб-планировщики.

## Ограничения: не подменяет Work полностью

Нельзя гарантировать безлимитные GPU, неограниченную глубину
автономной разработки, все внешние платформы и доступность
сервисов во всех регионах. Встроенный локальный ИИ остаётся
небольшой моделью, не GPT-6.

Компиляция APK доказывает наличие Android функционала, но не
серверную авторизацию или фактическую публикацию конкретного ролика.
Статус последней можно подтвердить только в Metricool Planner
и в соответствующей социальной сети.
