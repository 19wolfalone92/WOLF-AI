# 🎬 WOLF AI 16 — TikTok Studio напрямую, без Metricool

## Телефон Android — самый простой путь (без API, бесплатно)

1. Установи новую APK WOLF AI.
2. Напиши в обычном чате **«Тикток студио»** либо нажми
   ☰ → **«TikTok Studio · без Metricool»**.
3. Нажми **«Выбрать и проверить MP4»**. WOLF проверит кодек/размер,
   длительность, наличие аудио и возможный чёрный первый кадр.
4. Введи подпись/хештеги в поле WOLF.
5. **Путь А** — нажми **«Отправить проверенный MP4 напрямую в TikTok»**.
   Android откроет TikTok или системное меню «Поделиться».
   TikTok может проигнорировать переданную подпись — обязательно проверь её.
   Выбери обложку, приватность и **опубликуй самостоятельно** в TikTok.
6. **Путь Б** — нажми **«Открыть TikTok Studio в Chrome»**.
   Войди в TikTok и используй страницу `https://www.tiktok.com/tiktokstudio/upload`.
   Загрузи MP4, настрой описание/обложку/аудиторию и опубликуй.
7. Можно использовать встроенный браузер WOLF: включи JS для
   доверенной вкладки, войди вручную и выбери MP4 в HTML file chooser.
   Если WebView не допускает TikTok Login, используй Chrome.

Это **работает без Metricool**, но **НЕ является автопубликацией
в фоне на смартфоне**. WOLF не подтверждает публикацию вместо TikTok.

## Компьютер — дополнительный приватный Playwright uploader

Компьютер с Windows/Linux/macOS и CPU, Python 3.11+, свободное место
и доступ к сайту. Не нужна видеокарта. TikTok может блокировать
автоматизацию: это не поддерживаемая официальная API-интеграция.

Скачай WOLF-AI из GitHub, затем в папке проекта:

```bash
python -m pip install "playwright==1.64.1"
python -m playwright install chromium
```

### 1. Ручной вход

```bash
python -m wolf_ai.private_browser login --url https://www.tiktok.com/tiktokstudio --profile tiktok-studio
```

В видимом браузере самостоятельно войди в TikTok, включая 2FA.
Вернись к терминалу и нажми Enter. Сессия остаётся **только
на твоём компьютере**, в профиле WOLF. Не помещай её в GitHub.

### 2. Пробная проверка файла без загрузки

```bash
python -m wolf_ai.tiktok_studio --file "/path/to/video.mp4" --caption "Моя история #storyglitch" --dry-run
```

### 3. Подготовить черновик в TikTok Studio

```bash
python -m wolf_ai.tiktok_studio --file "/path/to/video.mp4" --caption "Моя история #storyglitch"
```

Скрипт откроет видимый Chromium на официальном TikTok Studio, найдёт
**однозначное поле MP4** и спросит текстовое подтверждение
`UPLOAD video.mp4`. После выбора файла WOLF попытается заполнить подпись.
Если интерфейс отличается, WOLF остановится, а не начнёт угадывать
положение кнопок. Проверь видео и закончи публикацию самостоятельно.

### 4. Разрешить одно реальное нажатие «Post»

```bash
python -m wolf_ai.tiktok_studio --file "/path/to/video.mp4" --caption "Моя история #storyglitch" --publish
```

Для отправки нужно **дважды подтвердить** действие:
`UPLOAD video.mp4` и `PUBLISH video.mp4`. Даже после клика
нужно убедиться, что **TikTok действительно принял пост**; WOLF
не считает сам факт нажатия успешной публикацией.

**Безопасность:** логин ручной, браузер видимый, учётные данные
не передаются в WOLF AI API, в GitHub Actions, HF, облачный Chromium
или Artifacts. Автоматического обхода CAPTCHA или 2FA нет.
Путь MP4 — только файл на твоём собственном компьютере.

## Полностью фоновая автопубликация: официальный TikTok API

Для стабильной автономной публикации через API нужны
developer app, Login Kit, официальный OAuth, разрешение
`video.publish`, аудит приложения для общедоступных постов.
Одного логина в TikTok Studio недостаточно для выдачи права API.

https://developers.tiktok.com/docs/en/content-posting-api-get-started

**Итог:** независимость от Metricool реализована через
официальный пользовательский интерфейс TikTok. Полностью автономный
надежный фоновой постинг с телефона без TikTok developer approval
пока не реализован.
