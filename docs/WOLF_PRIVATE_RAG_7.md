# 🐺 WOLF AI 7.0 — Private Knowledge & Source Intelligence

WOLF 7.0 improves the **information available to the existing local
GGUF**, not the size or raw intelligence of its neural network.

## Private local document knowledge (RAG)

The Android APK now includes a **local SQLite FTS4 knowledge base**.
The user chooses one source file at a time with Android's official
document picker, confirms ingestion and obtains a private searchable
index. No automatic disk scan, cloud API, vector database, paid
embeddings or uploaded source bytes.

Accepted **UTF-8 plaintext** file extensions include TXT, MD,
Markdown, CSV, LOG, JSON, XML, HTML, PY, JAVA, JS, TS, Kotlin,
YAML, SRT, INI, CSS and SQL.

**Current limits:** up to 30 documents, each up to 1.5 MB, up to
1,900 overlapping passages per document. Large documents must be
split into smaller text files. PDF, DOCX, photos, scanned pages and
binary files are **not** supported for ingestion in this version.
Do not rename a PDF to .txt: binary content is rejected.

**Workflow**
1. In WOLF AI open «Личная библиотека WOLF — RAG офлайн».
2. Tap «Добавить файл в локальную библиотеку». Select one permitted
   plaintext file via Android Files.
3. Confirm indexing after reviewing its filename and privacy notice.
4. Ask a question in the offline Qwen chat or the on-device Tool Agent.
   WOLF searches matching document passages, supplies a *bounded*
   excerpt to the installed local model, and displays real
   [filename · fragment N] source references generated by code.
5. To inspect and delete sources, tap «Показать загруженные документы»,
   then enter the numeric document ID for explicit deletion. An
   independently confirmed «Очистить всю библиотеку» deletes all
   imported text.

The indexed excerpts are data, not instructions. Documents can contain
untrusted text and may still mislead a small local LLM; real snippets
and visible source labels allow the user to verify claims.

**IMPORTANT BACKUP WARNING:** the knowledge base is app-private but
**not separately encrypted**, and Android backup is disabled in
the application manifest. GitHub Actions debug builds may have
different signing certificates, so uninstalling the old version to
install a newer APK can erase all imported documents. Keep
the original source files and reimport after reinstall. The old
LearningStore JSON export **does NOT include** this document index.

## Read-only GitHub project intelligence

The Tool Agent can inspect **current repository trees and small README
excerpts** from exactly six allowlisted GitHub projects:

- WOLF-AI
- Two-Worlds-Studio
- Shaira
- Williams
- Williams-AI
- English_Child

All inspections use HTTPS GET requests through GitHub's official REST
API, check real default branches and tree SHA values, filter sensitive
file paths, and limit source response sizes. The user's GitHub fine-grained
PAT is needed for private repositories. No arbitrary repo URLs,
automatic PRs, external code uploads, trades or TikTok publications
are authorized by a read-only chat question.

**Explicit source review:** the new Android card «Проверить настоящий исходник
выбранного проекта» lets you choose exactly one allowlisted repository,
a relative text source path and a start line. GitHub API reads only that
file (up to 50 KB), locally extracts up to 70 lines/1900 characters and
passes the selected excerpt to on-device Qwen for a non-executing review.
The user receives the real file SHA, GitHub URL with line anchors and
original excerpt even if local generation fails. This is NOT whole
repository comprehension. Filenames containing credentials/secrets
and files containing obvious tokens are refused. No source is sent
to an external hosted language model.

The agent can also retrieve actual WOLF GitHub Actions statuses and
explicitly requested Wikipedia sources. A generic debugging question
does **not** send text to Wikipedia; encyclopedia research intent
must be present. Local indexed documents, personal notes and
GitHub tokens are not sent to Wikimedia.

Repo inspection is intentionally **metadata-first**: it does not claim
to have thoroughly reviewed all source bodies. A full codebase review
requires further user-controlled file retrieval and larger model
context. The app's small Qwen remains less capable than GPT-6.

## Security and reliability

- No auto-publishing, payments, trading, privileged remote commands,
  CI merge or background permission escalation.
- All document ingestion and model-tool runs are initiated by the owner.
- Text is validated as UTF-8 and the ingestion stream is capped at
  1.5 MB; duplicated content is identified by SHA-256.
- All document writes occur inside one SQLite transaction.
- FTS4 query words are sanitized, quoted and passed as bound SQL
  parameters. Searches are bounded and ranked by lexical overlap,
  not by invented semantic similarity.
- Local model answers append source labels produced by code,
  making source attribution inspectable even when Qwen cannot
  consistently format citations itself.
- No claim of permanent learning: this is local retrieval of
  explicitly imported data, not fine-tuning of Qwen weights.
- GitHub read-only tree inspection is limited to approved repository
  names. An incomplete tree or unavailable README is declared.
