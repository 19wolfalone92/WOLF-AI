# 🐺 WOLF AI 16.0 — полный справочник возможностей и ограничений

## Что работает внутри Android

| Возможность | Команда / экран | Реальное действие | Ограничение |
|---|---|---|---|
| Локальный ИИ | Обычный вопрос | Qwen2.5-Coder 0.5B из APK через llama.cpp, без платного API | Качество существенно ниже крупных облачных моделей |
| Бесплатная Qwen3 | «Бесплатные модели» | Wi-Fi загрузка Qwen3 1.7B/4B с проверкой SHA-256, ручная установка | RAM, скорость и совместимость зависят от телефона |
| **Глубина 1–4** | «Настрой глубину» | 1–4 реальных локальных прохода с настройкой токенов | Повышает время и расход батареи; не равна GPT-6 |
| Глубокий ответ | «Подумай глубже: …» | План → ответ с документами → самопроверка → уточнение (по выбранной глубине) | Самопроверка не независимый фактчекинг |
| Автоматическая глубина | Переключатель в настройках | Глубокий режим для каждого обычного вопроса | Может сильно замедлить переписку |
| Режим 0 ₽ | «Включи бесплатный режим» | Блокирует запросы к потенциально платному HF LLM | Сторонние тарифы/лимиты сервисов не контролирует |
| Hugging Face LLM | «Спроси облачный ИИ: …» | По согласию отправляет один текстовый запрос | Требует доступа к API и соблюдения тарифов |
| Интернет-поиск | «Найди в интернете: …» | Получает реальные публичные результаты поиска | Сайты могут блокировать сбор |
| Исследовательский агент | «Проведи автономное исследование: …» | 2 поиска, до 4 публичных страниц, локальный синтез, журнал источников | Не читает частные аккаунты |
| Браузер WOLF | «Открой https://…» | HTTPS WebView, ручной JS, cookie-сессия WebView | Не универсальный браузерный агент |
| Браузерный маршрут | Помощник сайта | До 4 безопасных подтверждённых навигационных шагов | Только один HTTPS-домен; нет произвольных действий |
| Черновик формы | Помощник сайта | Ввод одного безопасного поля с предварительной проверкой | Сайт может автоматически сохранять изменения |
| Локальный анализ страницы | Помощник сайта | Читает ограниченный видимый текст и анализирует локально | Не читает формы и cookies |
| Android Accessibility | «Управление приложениями» | Подтверждённые ограниченные навигационные действия | Ручное разрешение; некоторые приложения блокируют |
| Кнопки приложения | «Покажи кнопки приложения» | Показывает названия видимых доступных безопасных элементов | Нет скрытого чтения экрана или паролей |
| Голос | Кнопки 🎙 / 🎧 | Android SpeechRecognizer + TTS; разговор с WOLF | Доступность и приватность зависят от голосового движка |
| Документы | + | PDF, DOCX, TXT и код — локальная библиотека с поиском | Отдельное обучение весов модели отсутствует |
| Память | Дополнительные инструменты | Локальные факты, примеры, зашифрованные резервные копии | База документов не делает автоматический LoRA |
| GitHub | «Проверь код…», «Собери APK» | Подтверждённые GitHub Actions и статус реальных запусков | Нужен GitHub PAT и права; Actions имеет лимиты |
| Видеопубликация через Metricool | Планировщик Metricool | Официальный OAuth и подтверждённые записи в сервис | Необязателен; зависит от API/тарифа |
| **TikTok напрямую** | «Тикток студио» | Выбор и анализ MP4, подпись, Android Share и открытие TikTok Studio | **Финальный Post с телефона делает пользователь** |
| Файловый ввод в TikTok Studio | Встроенный браузер / Chrome | Ручной выбор MP4 из Android при открытом официальном сайте | Studio может ограничивать WebView и запросить Chrome |
| Облачный Chromium | «Облачный браузер https://…» | GitHub CPU Playwright, отчёт и PNG в Actions Artifacts | Публичные сайты, БЕЗ логина/пароля |
| Сторонний сервис публикации | TikTok Studio, Chrome | Прямая работа без Metricool | Успех не подтверждается, пока TikTok сам не покажет его |

## Дополнительный приватный браузер на компьютере

`wolf_ai/private_browser.py`: видимый Chromium с ручным входом в аккаунт,
профиль остаётся на компьютере, не выгружается в CI.

`wolf_ai/tiktok_studio.py`: браузерный исполнитель TikTok Studio с
ручной авторизацией, локальным MP4 и подписью. Два отдельно
подтверждённых этапа: **UPLOAD** и (необязательно) **PUBLISH**.
Второй этап вызывает кнопку публикации только при явном подтверждении
владельцем. Скрипт не притворяется, что видео опубликовано, пока
результат не подтверждён в TikTok. Сайт может менять DOM, запрещать
автоматизацию или требовать дополнительных действий и CAPTCHA.
Скрипт не выполняет автоматический обход защитных проверок.

Подробная инструкция: `docs/WOLF_TIKTOK_STUDIO_16_RU.md`.

## Официальный TikTok Content Posting API

Для полностью автономной публикации *без браузерных кликов* нужен
**TikTok Developer App** с разрешением `video.publish`, согласие
владельца и официальная процедура аудита для общедоступных постов.
Без аудита API ограничен приватными публикациями, а не полноценным
управлением публичным TikTok-аккаунтом. Передавать client secret
в публичный репозиторий или GitHub Actions нельзя.

- https://developers.tiktok.com/docs/en/content-posting-api-get-started
- https://developers.tiktok.com/docs/en/content-posting-api-reference-direct-post
- https://developers.tiktok.com/docs/en/login-kit-overview

## Что НЕ реализовано

- Полная замена ChatGPT Work (большая облачная reasoning-модель, доступ
  ко всем приложениям/сайтам, безопасная универсальная мультиагентность).
- Скрытая авторизация TikTok и полная облачная сессия с cookies в GitHub Actions.
- Гарантированная автоматическая публикация/отложенный пост на Android.
- Полная нейросетевая самостоятельность, универсальное редактирование видео.
- Взлом ограничений Android, root, обход CAPTCHA.
- Отсутствие расходов на сторонние API, интернет или GitHub Actions без лимитов.

*Автоматизированные тесты исходников и сборка APK подтверждают
техническую сборку, но не подменяют реальные тесты на телефоне
и публичном TikTok аккаунте.*
