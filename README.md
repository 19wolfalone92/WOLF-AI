**WOLF AI полностью выделен в отдельный проект от видеостудии.** Исходники Android, Python-аудитор, тесты, CI и документация перенесены из `19wolfalone92/Two-Worlds-Studio`.

## 🧠 ВЕРСИЯ 5.0 — СИЛЬНЕЕ ЛОКАЛЬНЫЙ ИИ

- В APK сохранена **Qwen2.5-Coder 0.5B** для работы сразу после установки.
- Добавлен импорт **более мощных GGUF-моделей** прямо с Android:
  Qwen3 1.7B Q4_K_M (~1.28 ГБ) либо Qwen3 4B Instruct Q4_K_M (~2.5 ГБ).
  Скачивание внешних моделей — на усмотрение владельца, не за платный API.
- Проверка заголовка GGUF, размера и SHA-256, атомарное обновление,
  возможность вернуться к встроенной модели, без передачи данных в облако.
- Контекст до 4096 токенов, развёрнутые ответы до 768 токенов,
  лучшее форматирование вопросов и расширенная история чата.
- **🔊 Озвучка через Android TTS**, вручную, с возможностью использовать
  офлайн-голос (фактический сетевой доступ зависит от TTS-движка).
- Раздел моделей с ссылками на открытые GGUF и выбором объёма ответа.

[Подробнее: как импортировать Qwen3 и какие ограничения у локального ИИ](docs/SMART_LOCAL_AI_5.md).

**Критично:** 4B не равна GPT-6. На смартфоне большая GGUF может работать
медленно, перегревать устройство или не загрузиться из-за RAM. Автоматические
сборки проверяют APK, а реальную загрузку импортированного GGUF нужно
проверить на конкретном Android.

## 🐺 WOLF AI 4.0 — автономные миссии и более надёжные APK

- **GitHub Mission Control:** задания сохраняются в публичных GitHub Issues,
  но **запускаются только после отдельного подтверждения владельца**.
  Комментарий разрешения связан SHA-256 с содержимым Issue.
- **Автономная обработка:** каждые 2 часа GitHub Actions обрабатывает до
  трёх разрешённых задач аудита/тестирования, сохраняет состояние в Issue
  и публикует ссылки на реальные результаты, даже когда телефон выключен.
- **Защита от повторов:** перед запуском сохраняется резервирование;
  при неизвестном исходе запрос не повторяется самопроизвольно.
- **Параллельная работа:** GitHub проверки различных задач больше не
  отменяют друг друга из-за общего ключа concurrency.
- **🔎 Бесплатный поиск и исследование:** поиск в русской/английской
  Википедии, ссылки на источники, локальное объяснение через Qwen,
  добровольное сохранение фрагмента в приватной памяти без Work.
- **Плановое развитие:** еженедельное безопасное самоисправление Python
  с Pull Request на проверку человеком; еженедельная CPU-проверка
  обученного классификатора.
- **Подписанные обновления:** предусмотрен стабильный релизный Android
  keystore через GitHub Actions Secrets. Пока секреты не настроены,
  готовая APK остаётся debug-сборкой с возможной сменой подписи.

[Документация Mission Control 4.0 — что реально выполняется](docs/MISSION_CONTROL_4.md).

**Возможности сознательно ограничены:** система запускает фиксированные
аудиты/тесты, а не произвольные команды; не выполняет торговые операции,
не публикует видео без одобрения и не предоставляет безлимитные мощности.

## Новое в версии 3.1 — Metricool MCP Free

- **Встроенный официальный OAuth MCP клиент Metricool:** Android PKCE S256,
  динамическая регистрация клиента (если поддержана), защищённое хранение
  токенов через Android Keystore, проверка доступных брендов.
- **Планирование TikTok/Instagram/YouTube/Facebook через Free MCP**:
  отдельное пользовательское подтверждение каждой публикации, публичный
  HTTPS URL MP4, выбор даты/сети, возможность черновика.
  В отличие от платного REST API, сам MCP доступен даже Metricool Free,
  но сохраняется лимит Free — 20 постов/месяц.
- **Ограничение:** финальная OAuth-регистрация и фактическая публикация не
  подтверждены без входа владельца с телефона. При отказе сервера
  приложение не обходит ограничения.

Подробнее: [Metricool OAuth MCP и ограничения](docs/METRICOOL_MCP_FREE_OAUTH.md).

## 📲 Как получить APK

Открой **Actions → WOLF AI Android — Build APK → Run workflow**. После зелёной сборки открой **Artifacts**, скачай ZIP и извлеки APK. При выпуске в CI модель Qwen с проверенным SHA-256 и движок llama.cpp включаются **прямо в APK**. Termux и платный ИИ API не нужны.

## 🔐 Где выполняются операции

- **WOLF-AI:** собственный APK и Python-проверки.
- **Two-Worlds-Studio:** только целевые предпросмотры/тесты видеостудии, по явно выбранным действиям через GitHub.
- **Shaira, Williams, Williams-AI, English_Child:** аудит через явный выбор проекта, без изменения исходных репозиториев.

Для запуска CI с телефона требуется пользовательский **fine-grained GitHub PAT** с **Actions: Read and write** только для WOLF-AI и Two-Worlds-Studio. Токен не хранится в публичном GitHub или в ИИ-модели. Для чтения публичных CI статусов токен не нужен.

## Важные ограничения

Это не взлом Work и не бесплатный аналог GPT-6: встроенная модель 0.5B гораздо слабее облачных моделей. GitHub Actions имеет собственные лимиты. CI проверяет APK-сборку и содержимое, но **не заменяет ручное тестирование на реальном Android**. Торговля и публикация роликов не разрешены.
