# 🐺 WOLF AI 16.1.0 — исправления живого чата и голоса (Android)

Проверены код и CI после пользовательского отчёта: в реальном чате
вопрос «Что ты можешь ?» не соответствовал детерминированным
маршрутам HELP, поэтому приложение вместо быстрого ответа могло
пытаться загрузить Qwen GGUF. Один символ «?» отправлялся в модель,
которая требовала минимум 3 символа и выдавала ошибку.

**Исправлено в коде:**
- «Что ты можешь?», «Какие у тебя возможности?» и похожие вопросы
  дают **немедленный содержательный ответ в чате** без модели/сети.
- «?» даёт полезную подсказку, а не ошибку длины.
- «Ты не ответил на предыдущий вопрос» пытается безопасно
  восстановить обычный текстовый вопрос из локальной истории;
  никакие внешние действия автоматически не повторяются.
- Кнопка **«🔊 Проверить голос»** при включении озвучки сразу
  произносит тестовую фразу через Android TTS.
- В ☰ есть отдельная **«Проверить голос WOLF (тест Android TTS)»**.
- Если TTS не настроен или не поддерживает язык, WOLF показывает
  ошибку и предлагает открыть системные голосовые настройки.
- Ответ на **разовый микрофонный вопрос** теперь озвучивается
  даже при выключенной глобальной озвучке. Пользователь сохраняет
  право выключить чтение ответов.
- Настройка озвучки сохраняется между перезапусками.
- Статус долгого ответа показывает возможную первичную загрузку GGUF.

Это всё ещё зависит от фактически установленного на устройстве
SpeechRecognizer/TextToSpeech и не доказывает исправную работу на
конкретном телефоне без теста. Никаких постоянных фоновых микрофонов.

# 🐺 WOLF AI 16.0 — настраиваемая глубина + TikTok Studio без Metricool

## 🧠 4 режима глубины, настройка от 1 до 4 проходов

В основном чате: «Настрой глубину», «Режимы глубины», «Глубина 1»,
«Глубина 2», «Глубина 3», «Глубина 4». Отдельный экран включает:
- **Быстрый** — 1 проход локального llama.cpp и 256 токенов.

- **Экспертный** — 4 прохода, 768 токенов.
- Два ползунка для точной настройки **1–4 прохода, 128–768 токенов**.
- Переключатель применять выбранную глубину ко всем обычным вопросам.
  По умолчанию выключен для сохранения батареи и скорости.

План (если выбран) → ответ с локальными знаниями →
самопроверка (если выбрана) → дополнительная редакция (если выбрана).
**Самопроверка не заменяет независимые доказательства** и не делает
локальную 0.5B модель равной GPT. Внешний облачный LLM не вызывается.

## 💻 Видимый Chromium-компаньон для TikTok Studio без Metricool

  бесплатности любых внешних действий нет.

Контрольные суммы, официальные модели, ограничения и инструкция:

Локальная Qwen по-прежнему доступна бесплатно без интернета. Теперь WOLF
может **по отдельной явной команде** отправить один утверждённый вопрос в
облачную модель через официальный Hugging Face Inference Providers API.
Модель выбирается в русских настройках (по умолчанию
`openai/gpt-oss-20b:cheapest`, доступность зависит от провайдера).
Токен `hf_...` хранится отдельно от GitHub PAT под AES-256-GCM и Android Keystore.

Пример: `Спроси облачный ИИ: подробно спланируй систему видеопроизводства`.
Перед **каждым** запросом отображаются конкретный текст, модель и
предупреждение о тарифах. **История чата, документы, память, файлы,
cookie и GitHub PAT не отправляются.** Есть суточный лимит WOLF
12 запросов и отсутствие автоматических повторов; это **не**
гарантирует отсутствие тарифов у Hugging Face. Текущие бесплатные
кредиты для Free обычно очень небольшие (проверь актуальные условия).
Этот API выдаёт только текст, а не автоматически вызывает системные
инструменты Android или Work.

GitHub Models не используется: сервис закрыт 30 июля 2026 года.

Команды в WOLF чате:
- `Облачный браузер https://example.com`
- `Облачный браузер https://github.com/19wolfalone92 шаги: Repositories > Overview`

закрытые сайты/логины недоступны. Результат нужно проверять по

полной заменой ChatGPT Work, произвольным облачным компьютерным агентом

# 🐺 WOLF AI 11.0 — голосовой диалог, исследования и пакетные публикации

- **Больше действий Android**: установка времени будильника, таймеров, системные настройки экрана, звука, геолокации и разрешений WOLF через безопасные Android Intents. Системное приложение принимает окончательное решение.
- **Проверки:** JVM-тест маршрутизации, JDK-тест валидации графика публикаций, Python source contracts и Android CI.

**Важно:** WOLF 11 — не вторая Android-ОС и не копия облачного Work. Он не получает root, доступ к чужим приложениям, скрытую автоматизацию сайтов или право незаметно публиковать. Обычная Qwen 0.5B работает на телефоне и ограничена качеством модели. Google Play/Android ограничения доступа остаются. получить проверяемые результаты DuckDuckGo HTML, показывает до пяти
HTTPS-ссылок прямо в диалоге, а локальная Qwen объясняет только
доступные фрагменты. Никакого облачного ИИ и скрытой отправки
документов или истории. Если поисковик блокирует запрос, WOLF
честно сообщает об этом — браузер 🌐 остаётся доступен.

Универсального браузерного агента с логинами и кликами пока нет.
[Полная русская инструкция](docs/WOLF_CHAT_PHONE_10_RU.md).

## 🐺 Главное в WOLF AI 10.0 — не кнопки, а диалог

Вместо огромной панели приложение теперь запускается **с обычного
русского чата**. Ты пишешь или говоришь команду. WOLF выбирает
поддерживаемое действие и запрашивает разрешение перед доступом к
телефону, сайтам и GitHub. Снизу только поле сообщения, микрофон,
прикрепление документа, переключатель голоса и отправка.

**Реально добавлено:**
- новый ChatGPT-подобный тёмный интерфейс HomeActivity,
  отдельный логотип с геометрическим волком;
- нормальный встроенный HTTPS-браузер, поисковик и чтение одной
  публичной страницы для локальной модели только с согласия;
- голосовой ввод и автоматическая озвучка при включённом режиме;
- системные Android-команды через безопасные Intents:
  настройки, Wi-Fi, Bluetooth, камера, файлы, будильник,
  календарь, карты и звонилка;
- русский справочник со списком настоящих команд;
- старые технические кнопки доступны отдельно через ☰;
- реальные JVM-тесты распознавания команд в Android CI.

**[Подробная инструкция на русском](docs/WOLF_CHAT_PHONE_10_RU.md).**

**Не обещаем:** root, чтение чужих сообщений, свободное управление
любыми приложениями, облачный ИИ уровня GPT-6 или подтверждённые
публикации TikTok без OAuth. Внутренний браузер не является
Cloud Browser Work.


## 🛡️ WOLF AI 9.0 — ВСЯ личная рабочая среда в зашифрованном архиве

- **Новый формат .wolfpack:** теперь можно сохранить не только
  библиотеку документов, но также **личные факты и обучающие примеры,
  локальную историю чата и журнал GitHub-заданий**.
- **Перенос между APK:** архив защищён AES-256-GCM и паролем,
  а импорт проходит проверку целостности перед изменениями в SQLite.
- **Явное согласие:** экспорт запускается после выбора файла и пароля,
  восстановление требует отдельного подтверждения замены четырёх БД.
- **Восстановление после сбоя:** транзакции в отдельных SQLite-БД
  и резервные снимки позволяют попытаться откатить повреждённое
  восстановление. Совместная атомарность между четырьмя БД не гарантируется.
- **Секреты не экспортируются из хранилищ:** GitHub PAT, Metricool OAuth,
  ключи подписи, APK и GGUF остаются за пределами .wolfpack.
  При этом пользовательский текст чата может сам содержать личные данные.
- **Старый .wolfkb по-прежнему поддерживается:** он содержит
  только библиотеку документов WOLF 8.0; форматы не путаются.

[Инструкция WOLF 9.0: перенос всей личной рабочей среды](docs/PORTABLE_WORKSPACE_9.md).

**Внимание:** прежде чем удалять установленную APK, сохрани архив
и пароль. Без пароля восстановить шифрованную копию невозможно.
CI проверяет компиляцию/структуру, но перенос должен быть
подтверждён также на реальном Android-устройстве.

## 🔐 WOLF AI 8.0 — документы и резервные копии

- **📄 PDF и Word DOCX:** извлечение настоящего текстового слоя
  непосредственно на Android без облачного API. PDF до 4 МБ/45 страниц,
  DOCX до 4 МБ, индексируемый текст до 1,5 МБ. Сканированные страницы
  требуют OCR, которого пока нет.
- **📚 Документы становятся источниками ИИ:** текст включается в
  локальный SQLite FTS4 поиск и используется Qwen с указанием фрагментов.
- **🔐 Переносимая зашифрованная библиотека:** экспорт/импорт .wolfkb
  с AES-256-GCM, PBKDF2, паролем пользователя (от 12 символов).
  Целостность файла полностью проверяется до замены данных.
- **🛡️ Защита от потери при переустановке:** перед удалением отладочной
  APK сохрани .wolfkb. В него включены ТОЛЬКО документы; отдельно
  экспортируй заметки через JSON. Чат, задания, токены и GGUF в
  резервную копию документов не входят.

[Инструкция WOLF 8.0: PDF/DOCX и зашифрованные резервные копии](docs/WOLF_DOCUMENTS_ENCRYPTED_8.md).

**Внимание:** реальная работа с PDF/DOCX и перенос резервной копии
на смартфоне должны быть проверены отдельно. GitHub CI проверяет
исходники и сборку APK, но не заменяет тесты устройства.

## 📚 WOLF AI 7.0 — библиотека документов и реальные исходники GitHub

- **Чтение GitHub-исходников без права записи:** инструментальный агент
  получает актуальное дерево файлов, SHA и небольшой README из шести
  строго разрешённых репозиториев. При необходимости читает статусы CI.
- **🔬 Реальный анализ выбранного исходника:** новый раздел позволяет
  открыть безопасный текстовый файл до 50 КБ из одного из 6 проектов,
  указать начальную строку и получить объяснение ограниченного фрагмента
  от локальной Qwen, с настоящим SHA и ссылкой на GitHub. Без записи.
- **Безопасная отправка запросов:** отладочные запросы не отправляются
  в Wikipedia автоматически; внешний энциклопедический поиск только
  при явном исследовательском намерении.
- **Улучшена фактологическая проверяемость:** ссылки на оригинальные
  документы формируются кодом, а не выдумываются моделью.

[Инструкция WOLF AI 7.0: импорт документов, ограничения и приватность](docs/WOLF_PRIVATE_RAG_7.md).

## 🐺 WOLF AI 4.0 — автономные миссии и более надёжные APK

- **GitHub Mission Control:** задания сохраняются в публичных GitHub Issues,
  но **запускаются только после отдельного подтверждения владельца**.
  Комментарий разрешения связан SHA-256 с содержимым Issue.
- **Автономная обработка:** каждые 2 часа GitHub Actions обрабатывает до
  трёх разрешённых задач аудита/тестирования, сохраняет состояние в Issue
  и публикует ссылки на реальные результаты, даже когда телефон выключен.
- **Защита от повторов:** перед запуском сохраняется резервирование;
  при неизвестном исходе запрос не повторяется самопроизвольно.
- **Параллельная работа:** GitHub проверки различных задач больше не
  отменяют друг друга из-за общего ключа concurrency.
- **🔎 Бесплатный поиск и исследование:** поиск в русской/английской
  Википедии, ссылки на источники, локальное объяснение через Qwen,
  добровольное сохранение фрагмента в приватной памяти без Work.
- **Плановое развитие:** еженедельное безопасное самоисправление Python
  с Pull Request на проверку человеком; еженедельная CPU-проверка
  обученного классификатора.
- **Подписанные обновления:** предусмотрен стабильный релизный Android
  keystore через GitHub Actions Secrets. Пока секреты не настроены,
  готовая APK остаётся debug-сборкой с возможной сменой подписи.

[Документация Mission Control 4.0 — что реально выполняется](docs/MISSION_CONTROL_4.md).

**Возможности сознательно ограничены:** система запускает фиксированные
аудиты/тесты, а не произвольные команды; не выполняет торговые операции,
не публикует видео без одобрения и не предоставляет безлимитные мощности.

## 📲 Как получить APK

Открой **Actions → WOLF AI Android — Build APK → Run workflow**. После зелёной сборки открой **Artifacts**, скачай ZIP и извлеки APK. При выпуске в CI модель Qwen с проверенным SHA-256 и движок llama.cpp включаются **прямо в APK**. Termux и платный ИИ API не нужны.

## 🔐 Где выполняются операции

- **WOLF-AI:** собственный APK и Python-проверки.

## Важные ограничения

Это не взлом Work и не бесплатный аналог GPT-6: встроенная модель 0.5B гораздо слабее облачных моделей. GitHub Actions имеет собственные лимиты. CI проверяет APK-сборку и содержимое, но **не заменяет ручное тестирование на реальном Android**. Торговля и публикация роликов не разрешены.
